# 📖 About The Project

**Weather App** is a modern and fully responsive weather forecasting application built with **HTML**, **CSS**, and **JavaScript**, powered by the **OpenWeather API**.

The application enables users to search for any city around the world and instantly view the current weather conditions along with a detailed five-day forecast.

The project focuses on delivering real-time weather information through a clean, responsive, and user-friendly interface while practicing API integration and asynchronous JavaScript.

# ⚙️ Getting Started

Clone the repository

```bash
git clone https://github.com/Mohamedxismail/Weather-App.git
```

Navigate to the project folder

```bash
cd Weather-App
```

Open the project using **Live Server** or simply open `index.html` in your browser.

If you want to use your own API key, create a JavaScript configuration file and replace the existing OpenWeather API Key with your own.
